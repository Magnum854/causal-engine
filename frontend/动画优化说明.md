# 前端动画优化 - 安装指南

## 🎨 新增功能

实现了符合物理规则的优雅动画效果：

### 动画特性

1. **图谱缩放动画**
   - 点击节点时，整个拓扑图向左侧等比例缩小至 75%
   - 使用弹簧物理模型（Spring Physics）
   - 参数：stiffness=300, damping=30, mass=0.8

2. **图谱位移动画**
   - 图谱向左平移 15%，为详情面板腾出空间
   - 弹簧物理：stiffness=280, damping=28, mass=0.9

3. **模糊效果**
   - 图谱背景模糊 4px，突出详情面板
   - 平滑过渡：duration=0.3s, ease=[0.4, 0, 0.2, 1]

4. **抽屉滑入动画**
   - 详情面板从右侧滑入
   - 弹簧物理：stiffness=350, damping=35, mass=1
   - 带有回弹效果，符合真实物理规律

5. **遮罩层渐变**
   - 半透明遮罩层淡入淡出
   - 背景模糊效果（backdrop-blur）

## 🎯 使用说明

### 交互流程

1. **点击节点卡片**
   - 图谱自动缩小并向左移动
   - 背景模糊，突出焦点
   - 详情面板从右侧弹出

2. **关闭详情面板**
   - 点击遮罩层或关闭按钮
   - 图谱恢复原始大小和位置
   - 详情面板滑出屏幕

3. **物理效果**
   - 所有动画都带有自然的加速/减速
   - 弹簧回弹效果，符合真实物理
   - 流畅的 60fps 动画

## 🔧 动画参数调整

如需调整动画效果，编辑 `CausalGraphViewer.jsx` 中的 `ANIMATION_CONFIG`：

```javascript
const ANIMATION_CONFIG = {
  // 图谱缩放动画
  graphScale: {
    type: "spring",
    stiffness: 300,  // 弹簧刚度（越大越快）
    damping: 30,     // 阻尼（越大越少回弹）
    mass: 0.8        // 质量（越大越慢）
  },
  
  // 图谱位移动画
  graphTranslate: {
    type: "spring",
    stiffness: 280,
    damping: 28,
    mass: 0.9
  },
  
  // 模糊效果
  blur: {
    type: "tween",
    duration: 0.3,   // 持续时间（秒）
    ease: [0.4, 0, 0.2, 1]  // 缓动曲线
  },
  
  // 抽屉滑入
  drawer: {
    type: "spring",
    stiffness: 350,
    damping: 35,
    mass: 1
  }
}
```

### 参数说明

- **stiffness**：弹簧刚度，值越大动画越快
- **damping**：阻尼系数，值越大回弹越少
- **mass**：质量，值越大动画越慢、越有重量感
- **duration**：动画持续时间（秒）
- **ease**：缓动曲线，控制加速/减速

## 🐛 故障排除

### 问题 1：动画卡顿
**解决方案**：
- 检查浏览器性能
- 降低 stiffness 值
- 增加 damping 值

### 问题 2：回弹过度
**解决方案**：
- 增加 damping 值（如 40-50）
- 减少 stiffness 值

### 问题 3：动画太慢
**解决方案**：
- 增加 stiffness 值
- 减少 mass 值
